# LyricSide Privacy Policy

Last updated: 24 September 2026

LyricSide does not collect, sell, share, or transmit personal information to the developer. It contains no analytics, advertising SDKs, account system, or tracking code.

When a supported YouTube or YouTube Music page is opened, the extension may send the detected track title, artist name, and track duration to LRCLIB (`lrclib.net`) solely to search for and retrieve matching lyrics. A selected lyrics record ID may also be sent when retrieving a specific lyrics record.

LRCLIB is an independent third-party service. Requests made directly to LRCLIB may expose ordinary connection information, such as the user's IP address, to that service. LRCLIB's own privacy practices apply to requests sent to it.

Extension preferences, manually selected lyrics records, and per-video synchronization offsets are stored locally on the user's device using `chrome.storage.local`. This information is not sent to a developer-operated server.

LyricSide does not request access to browsing history, cookies, passwords, email, identity information, or unrelated websites. Its content script runs only on YouTube and YouTube Music, and network host access is limited to LRCLIB.

## Limited Use

LyricSide uses user data only to provide its core functionality of finding, displaying, and synchronizing lyrics.

User data is not sold, used for advertising, profiling, creditworthiness evaluation, or unrelated purposes.

Data is sent to LRCLIB only when necessary to search for or retrieve lyrics.

LyricSide's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

LyricSide is not affiliated with, endorsed by, or sponsored by YouTube, Google, or LRCLIB.
